# port-sandbox

Evidence for `docs/wails-port-audit.md`, and code that the port reuses. Nothing here ships, and the app never imports it.

Needs Go 1.26, bun, and `ffmpeg`/`ffprobe` on `PATH`. Windows only.

| Folder | What it holds | Run |
|---|---|---|
| `gotests/` | Go tests for every design in the report (`go test -race`) | `cd gotests && go vet ./... && go test -race ./...` |
| `app/` | A Wails v3.1.0 app (`wails3 init -t react`, non-Windows assets removed) exposing probe services | `cd app && PACKAGE_MANAGER=bun wails3 build` → `bin/probe.exe` |
| `cdp/` | Playwright `connectOverCDP` probes that drive `app/bin/probe.exe` in WebView2 | `cd cdp && bun install && bun harness.ts ../app/bin/probe.exe probe-bridge.ts` |
| `ranking/` | Real search pages plus the TS side of the ranking comparison (`gotests/ranking`) | `bun ranking/capture.ts` re-captures pages (needs the current app's yt-dlp) |
| `limits/` | Generates the contract limits with `z.toJSONSchema` | `bun limits/gen.ts` |
| `fixtures/` | Audio fixtures, generated by `gen.sh` (the upload tests run it when they're missing) | `sh fixtures/gen.sh` |

Notes:
- `gotests/ranking`, `gotests/upload` and `limits/` read this repo's own sources (`src/bun/searchRanking.ts`, `contract/`, `node_modules/`), so run `bun install` at the repo root first.
- `gotests/winproc`'s yt-dlp test skips unless the current app has installed `%LOCALAPPDATA%\VexWave\bin\yt-dlp.exe`.
- The CDP probes use port 9333, because 9222 is taken by a system service on the reference machine. `PROBE_CDP_PORT` turns on `Windows.AdditionalBrowserArgs`; the environment variable `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS` has no effect on a Wails app.
- Run the whole suite again before every Wails version bump.
